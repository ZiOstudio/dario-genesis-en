# 项目全记录：Dario Genesis 英文配音 / 英文字幕版

> 本文件是「Dario Genesis 英文版」项目的完整技术与社会化记录，供执行代理（DSH）整理为 GitHub 仓库时直接引用。
> 文中所有数字均为实测值，不含估算。凡标注「未验证」的条目，不得在仓库文档中改写为确定结论。

## 0. 一句话概述

把 B 站中文科普短片《达里奥创世录》（BV1mEnb6LEnC）改造成**英文配音 + 英文硬字幕**的海外发行版：
重新翻译全文旁白、用神经网络语音合成 53 段英文配音并按原时间轴逐段贴合、重混整条音轨、
把英文字幕烧进画面、并在片头标题卡上追加一行中英双语译者署名。

**这是一部派生作品（derivative work），不是原创。原作的一切归原作者。**

## 3. 改动清单（逐项，含技术参数）

### 3.1 文本层

- 中文 2535 字 → 英文 1501 词，语义等价翻译，保留原文的讽刺语气与术语
- 切分为 **53 段**，与上游 `数据/ch*.js` 的 53 段严格一一对应（`charTimes` 长度 == 文本长度 + 1，53/53 命中）
- 章节结构沿用原作五章，章偏移：ch1=0、ch2=190.5333、ch3≈353.83、ch4=421.86667、ch5≈518.87（ch3/ch5 为推算值）

### 3.2 声音层

**配音**

| 项 | 值 |
|---|---|
| 引擎 | `edge-tts`（微软 Edge 神经网络 TTS，免费无 key） |
| 音色 | `en-US-AndrewMultilingualNeural` |
| 段数 | 53 |
| 失败数 | 0 |
| 语速拟合 | 物理模型 `dur ≈ A / (1 + rate/100)`，取多次调用的中位数反解，容差 1.3% |
| 拟合精度 | 中位偏差 **0.50%**，p90 **1.50%**，最大 **8.8%**（S23） |
| 轻微压缩 | **22 段**用 `atempo` 收口，范围 1.0009–1.0888（最大 S23 = 1.0888） |
| 电平一致性 | 干声实测 −21.0 / −21.0 / −21.4 LUFS，峰值 −3.3 ~ −4.2 dBFS → 单一全局增益即可，无需逐段归一化 |

**混音**

| 项 | 值 |
|---|---|
| 采样率 | 48000 Hz 立体声 |
| 伴奏床增益 | **−6.3 dB** → 约 −26.1 LUFS |
| 人声增益 | **+5.0 dB** → 约 −16 LUFS |
| 人声支路限幅 | `alimiter=level=0:latency=1:limit=0.78`（`level=0` 必须显式指定，否则默认自动加 +1.8 dB） |
| 人声/伴奏分离度 | 约 10 LU |
| ducking / sidechain | **不使用**（会明显抽吸，改为固定增益） |
| 段间间隙 | 0.06 s |
| 母版拼接点 | **676.4417 s**（详见 3.2.1） |
| 混音前直出 | I −13.7 LUFS / TP +3.0 dBTP / LRA 4.5 LU |
| **最终** | **I −15.5 LUFS / TP −2.5 dBTP / LRA 4.5 LU**，立体声峰值 0.7400，过采样越界 0 次 |

**3.2.1 片尾拼接点是怎么定的**

母版 703.928 s，而作曲脚本的覆盖只到约 680 s，片尾 22.3 s（字幕卡 + 配乐）不在覆盖范围内，必须从母版音轨直接截取。

初版按计划在 681.67 s 切入，结果**切掉了一个音符**——那里正好在一段渐强中。改为扫描全曲最长的数字静音段：

- 实测真数字静音区间：**672.326 s – 680.558 s**（7 s 余，对应作曲脚本的 `TAIL=7.0`）
- 取该区间**中点**作为拼接点 → **676.4417 s**，配乐在 680.558 s 才渐入，因此不会切断任何音符

## 6. 已知限制（必须如实写入 README）

1. **画面内中文未翻译。** 部分镜头内部有中文文字（如"提交申诉"的后台界面、祖冲之割圆的纸面标注）。这些是画面像素的一部分，不是字幕层，翻译需要重渲染或逐帧遮挡。经评估：上游 40 个镜头只公开了 4 个母版原型，`production/` 从未发布，**重渲染整片不可行**；人工遮挡重制需 2–4 周。**决定：保留中文，作为"中文风味"接受。**
2. **配音是 TTS，不是真人。** 已做到逐段语速贴合与统一电平，但韵律与情感不及真人配音。
3. **上游只公开了 4/40 个镜头的母版。** 本项目的所有工作都建立在**已发布的成品视频**之上，不依赖也无法依赖上游的合成管线。
4. **软字幕版没有片头署名。** 因为该版视频流是 `-c:v copy`，无法叠加字幕层。署名只存在于主发布版与仓库文档中。
5. **章节偏移 ch3 / ch5 是推算值**（由 ch1/ch2/ch4 的等差结构反推），非上游明示。
6. **本译文未经过母语审校流程**，仅由译者本人校对。欢迎在 Issues 中提出修改建议。

## 9. 常见错误（**不要做**）

| 错误 | 后果 |
|---|---|
| **Fork 上游仓库再上传** | Fork 是代码层动作，会永久挂 `forked from null0526/dario-genesis`，且继承上游顶层 MIT 许可 → 出现「LICENSE 写 MIT、内容实为 NC-SA」的矛盾。本项目不是代码分支 |
| 把 mp4 `git add` 进仓库 | 单文件 100 MB 硬上限，push 被拒；且 blob 永久留在历史里，删除需重写历史 |
| 用 Git LFS 存视频 | 免费额度 1 GB 存储 / 1 GB 月流量，两个文件 1.38 GB，clone 两次即耗尽，仓库变砖 |
| 把内容层改成 MIT | 违反 ShareAlike，属许可违约 |
| 删除或弱化来源标注 | 违反 BY，且是这类作品最不该犯的错 |
| 提交 `repo/` 或 ffmpeg 二进制 | 把第三方代码与 200 MB 二进制混进自己的仓库 |
| 重新编码视频"顺手优化" | 已定稿的响度与画质会被破坏，且失去可复现性 |
