# 《达里奥创世录》原始工程 · 索取清单

> 目的：在**不改动创作意图**的前提下，把画面内中文替换为英文，产出海外发行版。
> 下面每一项都标注了「为什么需要」——缺少任一项，复现都会失败或对不上现有成片。

---

## 一、代码与工程（最优先）

| 需要什么 | 为什么 |
|---|---|
| **完整生产目录**：`experiments/`、`outputs/`、`production/`、`测试场/`、`留档/` | 公开仓库只有 4 个原型镜头，全片几十个镜头都不在里面 |
| **剪辑表 / 时间线**：镜头顺序、每个镜头的入点·出点（或拼接脚本） | 重渲后要按原剪辑点拼回去，否则时长和节奏会变 |
| **后期工程**（Premiere / AE / 或 ffmpeg 脚本） | 片中有大量**叠化转场**，那是在后期做的。换掉一个镜头，它与前后镜头的叠化必须重做 |
| **所有 `shot.html` 及其引用的资产**：png、着色器、`_d3f0.png` 这类"取自别镜头首帧"的贴图 | `镜头/01-要有光/设计说明.md` 里明确写了：`_d3f0.png` 取自 `day3-ferns/film.mp4` 第 0 帧，**第三天若重渲这张要重取**——存在镜头间资产依赖链 |
| **渲染脚本的最新版**（`render.py` 或等价物） | 公开版是原型，正式版可能有改动 |
| **依赖锁定**：`package.json` / `requirements.txt` / playwright 版本 / Chromium 版本 | 逐帧渲染结果对 Chromium 版本敏感，差一个版本可能像素就不一样 |

## 二、画面文案的源数据

| 需要什么 | 为什么 |
|---|---|
| `数据/ch*.js` 的**最终版** | 公开仓库里 ch5 有 `ch5.js` 和 `ch5-provisional.js` 两个版本，说明有版本分叉 |
| **画面文字的源数据**（如果有）：UI 文案、标签、章节标题的数组/JSON | 有些是硬写在 `shot.html` 里的（如 `const PARAMS=['波长','光强','渲染参数']`），有些可能抽到了数据层。有源数据就不用逐文件抠 |
| **译名对照**（如果作者已有英文版命名习惯） | 避免把 `蒸馏`、`配额耗尽`、`旁路权限` 译得跟原意跑偏 |

## 三、字体（最容易漏，漏了就白渲）

| 需要什么 | 为什么 |
|---|---|
| `Noto Serif CJK SC`、`Noto Sans CJK SC` 字体文件 | `shot.html` 里显式 `document.fonts.load('46px "Noto Serif CJK SC"')`，**本机没有这两个字体**，缺了会掉到回退字形 |
| `SERIF` / `SANS` / `MONO` 三个变量指向的**拉丁字体**及其字重 | 换成英文后走的是拉丁字体，必须和原设计一致，否则英文的观感会和画面其他元素打架 |

## 四、环境与版本（决定能否 1:1 复现）

需要作者回答：

1. **操作系统**、**Chrome/Chromium 具体版本**、**Playwright 版本**、**显卡型号**
2. 渲染时的 `--sub` 参数（公开文档说成片用 8 次子帧采样，需确认全片一致）
3. 成片的编码链（直接导出的参数，或所用软件与设置）

已知的成片规格，供作者对照：

- 1920×1080，30 fps，时长 **703.93 s**
- 视频 H.264 High，8655 kb/s；音频 AAC-LC 48 kHz 立体声，242 kb/s
- 整体响度 −16.14 LUFS，真峰 −1.86 dBTP

## 五、一个必须澄清的时基问题 ⚠️

我用互相关对齐过：`数据/` 里 `charTimes` 的时间轴，和正式成片**差了 3.05067 秒**（成片开头多了一张标题卡，是数据产出之后才加的）。

请作者确认：

- 正式发布的剪辑，相对 `数据/` 的偏移量是多少？
- 有没有**与成片同步后的** `charTimes` / 剪辑表？
- 如果重渲，是按 `数据/` 的时间轴出片，还是按成片时间轴出片？

这一条搞错，所有镜头都会整体错位 3 秒。

## 七、传输方式建议

- 代码与资产打成 zip / 7z，走网盘或 Git 仓库（**保留目录结构**，别拍平）
- 字体单独给（CJK 字体包体积大，但也别省）
- 如果 `production/` 里有几个 GB 的视频中间件，**优先给"每个镜头的无声母版"**，那比给工程文件更省事

2. **全部 `shot.html` + 它们的资产**
3. **字体**
